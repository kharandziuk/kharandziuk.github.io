## Exercise types

- **Order words** — drag-and-drop into correct order. The app shows a fixed German instruction for the page type once; each item shows fixed `lead` / `trail` text and a word bank, not the full answer sentence. The user builds the missing part by dragging a token onto the answer line **or** clicking it to append; both gestures are always available, and a placed token goes back to the bank the same two ways. Graded on the joined token sequence.
- **Fill in gaps** — supply missing words or fragments. The prompt is the sentence itself, each blank rendered as an inline input. In `word` mode a blank takes a whole word (article, preposition, pronoun); in `ending` mode the stem stays visible and only the ending is typed. Every blank must match.
- **Transform sentences** — rewrite or rephrase the prompt. The prompt carries the source sentence and the required transformation (tense, structure, connector); the user retypes the whole sentence in one textarea. Graded as a single string.
