# Agent notes

**jQuery** static drill app. Deploy to **GitHub Pages** from the repo root.

**Screens:**
1. **Loader** — paste exercise JSON, then load.
2. **Cheatsheet** — `data/cheetsheet.md` after a successful load; **Start drills** continues.
3. **Session** — paginated drills (fill-in blanks and word order).
4. **Summary** — stats and mistakes after the last page.
